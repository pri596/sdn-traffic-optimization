About the Project

Detecting Wireless Network Attacks Using Machine Learning

This project focuses on enhancing cybersecurity by detecting malicious activities in wireless networks using machine learning algorithms. By analyzing network traffic data, our system classifies various types of attacks such as DoS, spoofing, and probing. The goal is to provide an intelligent and automated solution for identifying threats in real-time, improving the overall security of wireless communications.

Blackhole Attack

Intercepts and drops all packets, creating a “black hole” in the network. Detected through abnormal traffic loss patterns.

Flooding Attack

Overwhelms the network by sending excessive requests, degrading performance. Detected by sudden spikes in traffic.

Grayhole Attack

Similar to Blackhole but selectively drops packets. Detected through inconsistent delivery patterns.
